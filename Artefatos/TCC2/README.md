# TCC 2 — Artefatos Atualizados

Nesta pasta estão reunidos arquivos como diagramas, imagens, telas do sistema e demais recursos utilizados na documentação do projeto.

## Observação

Os arquivos presentes neste diretório representam versões atualizadas dos materiais utilizados como apoio à documentação, apresentação e continuidade do desenvolvimento do sistema.
